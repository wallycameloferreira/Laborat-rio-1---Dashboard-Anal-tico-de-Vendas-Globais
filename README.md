# 📊 Laboratório 1 — Dashboard Analítico de Vendas Globais

> **Transformando dados de vendas em informações para apoiar decisões de negócio.**

Este projeto apresenta um **Dashboard Analítico de Vendas Globais**, desenvolvido com foco na análise de dados comerciais e na resposta a perguntas de negócio por meio de indicadores, gráficos, filtros interativos e análise geográfica.

O dashboard permite explorar os dados de forma dinâmica, possibilitando diferentes perspectivas sobre vendas, categorias de produtos, descontos, prioridades de entrega e desempenho por país.

---

## 🎯 Objetivo do Projeto

O objetivo deste laboratório é desenvolver uma solução analítica capaz de transformar dados de vendas em **informações claras, relevantes e visualmente acessíveis**, permitindo responder perguntas importantes para o negócio.

A análise foi estruturada para facilitar a identificação de padrões e diferenças de desempenho entre:

- 🌎 Países
- 📦 Categorias de produtos
- 🗂️ Subcategorias
- 👥 Segmentos
- 📅 Anos
- 🚚 Prioridades de entrega
- 💰 Valores de venda
- 🏷️ Descontos

---

## 💡 Perguntas de Negócio

O dashboard foi desenvolvido para responder às seguintes perguntas:

### 1️⃣ Qual o valor total vendido?

Apresenta o **valor total das vendas**, permitindo acompanhar o desempenho comercial geral.

### 2️⃣ Quantas vendas foram realizadas por categoria de produto?

Permite analisar a **quantidade de vendas por categoria**, facilitando a comparação entre os diferentes grupos de produtos.

### 3️⃣ Quantas vendas foram realizadas por país considerando a prioridade de entrega?

Analisa a quantidade de vendas por **país**, considerando também a **prioridade de entrega**, possibilitando uma visão mais detalhada da distribuição das vendas.

### 4️⃣ Qual foi a média de desconto nas vendas por subcategoria de produto?

Apresenta a **média de desconto por subcategoria**, permitindo analisar como os descontos estão distribuídos entre os produtos.

### 5️⃣ Quais países tiveram maior média de valor de venda?

Utiliza uma **visualização geográfica em mapa** para demonstrar a média do valor de venda por país e facilitar a análise da distribuição geográfica dos resultados.

---

## 🎛️ Filtros Interativos

O dashboard permite ao usuário explorar os dados utilizando filtros por:

| Filtro | Aplicação |
|---|---|
| 📅 **Ano** | Análise por período |
| 👥 **Segmento** | Análise por perfil de cliente |
| 🌎 **País** | Análise geográfica |

Os gráficos e indicadores são atualizados de acordo com os filtros selecionados, proporcionando uma experiência de análise mais dinâmica.

---

## 📈 Principais Visualizações

O dashboard reúne diferentes recursos de visualização para facilitar a interpretação dos dados:

- **KPI de valor total vendido**
- **Gráfico de vendas por categoria**
- **Gráfico de vendas por país e prioridade de entrega**
- **Análise de média de desconto por subcategoria**
- **Mapa de média de valor de venda por país**
- **Filtros interativos por ano, segmento e país**
